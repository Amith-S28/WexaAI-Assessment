Graph Database Cloud Benchmarking & Evangelism Pipeline

An end-to-end editorial architecture for evaluating CognoDB Cloud against four capped competitor platforms under strict 0.5 vCPU / 256 MB RAM resource parity, gathering multi-dimensional percentile latency profiles, and publishing a reproducible public study.

Milestone 01 · Data & Fairness Setup

Standardized Ingest & Strict Parity

  • Dataset Curation: Sourcing SNAP soc-pokec / wiki-Vote graph (~350,000 edges) calibrated to maintain comfortable overhead in 256 MB RAM.
  • Hardware Parity: Every competitor database is deployed under identical resource limits (0.5 vCPU, 256 MB RAM, 1 GB disk) via Docker Compose or native free tiers.
  • Ingest Benchmarking: Ingestion throughput (nodes/sec, rels/sec) and index build duration captured with chunked batching.

Milestone 02 · Workloads & Precision

Multi-Hop Traversals & Concurrency

  • Automated Warmup: 20 initial queries prime query caches and connection pools before taking measurements.
  • Microsecond Precision: ≥100 iterations per query workload reporting p50, p90, p95, and p99 percentiles (point lookup, indexed filter, 1/2/3-hop traversals).
  • Concurrency Sweeps: Async stress generator simulating 1, 10, and 40 concurrent workers under an 80% read / 20% write transaction mix.

Milestone 03 · Evangelism & Analysis

Public Article & Root-Cause Insight

  • Root-Cause Reasoning: Technical analysis explaining why performance diverges (GraphBLAS matrix math vs in-memory pointer chasing vs JVM overhead).
  • Publication-Grade README: Self-contained, beautiful charts, reproducible one-line CLI runner, and transparent disclosures (network RTT, throttling).
  • Evangelism Packaging: Crafted as a compelling engineering deep dive designed for community engagement and technical authority.
